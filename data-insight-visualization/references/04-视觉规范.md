# 视觉规范

审美不是「好看」，而是**让正确的信息获得正确的注意力权重**。四个可控杠杆：层级、色彩、密度、细节。

---

## 一、层级

一屏只允许 **1~2 个视觉重心**。手段按有效性排序：

1. **尺寸**：主图与辅图高度差 ≥ 1.5 倍
2. **位置**：重心放左上或中央
3. **色彩权重**：重心用饱和色，其余用灰阶或低饱和
4. **留白隔离**：用空白分开，比加边框有效

**验收方法**：眯眼测试。把眼睛眯到看不清文字，第一眼落在哪？如果三处同样重，就是没有层级。

页面结构建议：

| 层级 | 高度 | 内容 |
|---|---|---|
| 页头 | 60~80 | 标题（结论句）+ 副标题（口径）+ 数据截止时间 |
| KPI 区 | 100~120 | ≤ 6 张，一行排满 |
| 主图 | 380~420 | 1 张，占满宽 |
| 次级图 | 300~380 | 2 列网格 |
| 明细 | 不限 | 表格或查询模块 |

## 二、色彩

### 结构

**1 个主色 + 一组中性灰 + 1 个强调色**。数据系列色 5~7 个封顶，超过说明需要合并类别。

| 角色 | 取值 | 用途 |
|---|---|---|
| 主色 | `#2f87c9` | 主系列、主要交互 |
| 深色 | `#12325e` | 标题、坐标轴文字 |
| 正文 | `#1d2939` | 正文 |
| 次级文字 | `#667085` | 副标题、单位 |
| 辅助文字 | `#98a2b3` | 注释、脚注 |
| 页面底 | `#f2f5fa` | 背景 |
| 卡片 | `#ffffff` | 容器 |
| 网格线 | `#eef2f7` | 横向网格 |
| 坐标轴 | `#d0d7e2` | 轴线 |
| 强调 | `#c0392b` | 异常、断档、超阈值（仅此三类） |

### 分类色板（固定顺序，不要随机）

`#5470C6` 蓝、`#91CC75` 绿、`#FAC858` 黄、`#EE6666` 红、`#73C0DE` 青、`#9A60B4` 紫、`#3BA272` 深绿

### 规则

- **同一实体跨图同色，且颜色不随排序变化**。读者第二次看到红色不必再查图例。
- 连续量用**单色阶**（浅→深），不要用分类色板表达连续值。
- 避免：彩虹渐变（无排序含义）、红绿并置（红绿色盲约占男性 8%）、纯黑底上的高饱和色。
- 强调色只给「需要行动」的信息，用满一屏等于没有强调。
- 对比度：正文与背景 ≥ 4.5:1；大字号 ≥ 3:1。

## 三、密度与留白

| 项 | 规范 |
|---|---|
| 栅格 | 12 列，或 2 / 3 / 6 分栏 |
| 间距 | 取 8 的倍数：8 / 16 / 24 / 32 |
| 内容最大宽 | 1440，左右留白 24 |
| 卡片 | 圆角 12、内边距 18、阴影 `0 1px 2px rgba(16,24,40,.04)` |
| 图表高度 | 主图 420、一般 380、小图 300 |
| 一屏容量 | ≤ 4 张主图，或 8 张卡片 + 1 张图 |

超过容量就分屏、加 Tab 或下移，**不要压缩间距硬塞**。

### 数字格式

| 类型 | 格式 | 示例 |
|---|---|---|
| 整数 | 千分位 | `13,409` |
| 百分比 | 一位小数 | `47.4%` |
| 金额 | 千分位 + 单位写在轴/列头 | `1,234`（千元） |
| 小数 | 全页统一位数 | `3.2` |
| 缺失 | 统一符号 | `—`（不要混用 `N/A`、`null`、`/`） |
| 单位 | 写在轴标题或列头 | 「单位：台」「金额：万元」 |

### 字体

- 字体栈：`-apple-system, "Segoe UI", "Microsoft YaHei", "PingFang SC", sans-serif`
- 不引外部字体：离线可用、加载不闪
- 字号阶梯（只留 4 级）：页标题 22~26 / 卡片标题 15 / 正文 13 / 说明 12
- 字重 ≤ 3 种：400 / 600 / 700
- 数字用 `font-variant-numeric: tabular-nums`，避免列内数字左右跳
- 不用 emoji 当图标：跨平台渲染差异大

## 四、图表细节

### 必须做

- 网格线只留横向、浅灰；去掉外边框、背景色块
- 条形图降序排列（除非有自然顺序：月份、阶段、等级）
- 轴标题写单位
- 图例位置固定（顶部或底部），不要每图不同
- tooltip 显示原始值 + 占比，不要让读者自己算

### 可以省

- 图例与颜色重复（≤ 3 个系列且已直接标注时，图例是冗余）
- y 轴刻度线（保留网格即可）
- 数值标签（点数 > 12 时改 tooltip）

### 轴与标签

- 柱状图、面积图：y 轴从 **0** 开始
- 折线图：可以不为 0，但必须标注首尾值
- 标签旋转 45° 是「类目太多」的信号 → 先改聚合粒度
- 标签互相遮挡时：优先 tooltip，其次末端标注，最后才缩短标签

### 配色与图型的一致性

- 同一实体在趋势图、构成图、热力图、明细表里用同一颜色
- 热力图色阶要有图例，且标明「浅 = 早 / 少，深 = 晚 / 多」
- 缺失值用统一的中性浅灰，并加文字说明，不要用背景白「假装没有」

## 五、深浅色

- **默认做浅色**：打印、投影、截图分享都更稳
- 深色只用于两个场景：长时间盯屏的监控大屏、夜间使用的工具
- 深色不是把颜色反过来：
  - 背景用 `#121417` 一类近黑，不用纯黑
  - 系列色降饱和、提亮度
  - 文字对比度 ≥ 4.5:1
  - 浅黄、浅绿在深底上最容易失效，必须实际验证

---

## 六、单文件与性能

- 单文件 HTML 内联 CSS / JS / 数据，双击可离线打开
- 图表库整包内嵌约 1 MB；低配机器同屏 > 12 张图会掉帧 → 分屏或懒加载
- 数据只内嵌聚合结果，不要内嵌原始明细（体积与首屏时间都不可控）
- 首次渲染后统一注册一次 resize，后加模块各自注册，不要改同一个数组

---

## 七、可访问性底线

- 不只靠颜色传达状态：异常点同时加形状或文字标注
- 交互元素有 hover / focus 态
- 表格有表头，数字列右对齐，文本列左对齐
- 打印或导出 PDF 时，浅色方案优先
