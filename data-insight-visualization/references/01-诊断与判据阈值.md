# 诊断与判据阈值

所有阈值都是**默认值**，不是定律。数据量小、业务波动大、季节性强的场景要放宽，但必须说明放宽的理由。文中「pp」= 百分点。

---

## 一、粒度与主键

### 判据

| 观察 | 结论 | 动作 |
|---|---|---|
| 候选键最大重复数 = 1 | 该键唯一，可作主键 | 直接使用 |
| 重复率 < 0.1% 且重复行内容完全相同 | 可能是合法重复（同刻同额） | 确认后可去重 |
| 重复率 0.1%~0.5% | 可疑 | 人工抽查 5~10 组重复，判断是「更细粒度」还是「重复上报」 |
| 重复率 > 0.5% | 粒度判断错误或数据质量问题 | 停止聚合，先查清 |
| 组合键才唯一 | 真实粒度比单列更细 | 用组合键，写进交付物 |

### 操作

1. 对每一列算 `唯一值数 / 行数`。接近 1 的列是主键候选。
2. 对候选做主键重复检测；不唯一时，加时间列或类别列组成组合键再测。
3. 组合键搜索顺序：业务单号 → 时间 + 实体 → 时间 + 实体 + 类别。组合数超过 500 万时先抽样。

**一行代表什么，要能用一句业务话讲出来**（「一行 = 一个订单的一个 SKU」）。讲不出来就是错的。

## 二、时间

### 必查五项

| 项 | 算法 | 阈值与动作 |
|---|---|---|
| 跨度 | `max(date) - min(date)` | 记录首尾；判断首尾是否为完整自然周期 |
| 密度 | 去重天数 / 日历天数 | < 95% 视为有缺口，列出缺失日 |
| 缺失 | 逐日比对日历 | 缺失 > 5% 先问原因，不默认补 0 |
| 最大断档 | 相邻日期差的最大值 | > 7 天说明数据源中断，需分段看趋势 |
| 时区 | 检查是否 UTC 存储 | 跨境数据必须统一时区后再做日粒度 |

### 两个常见误判

- **把「没有发生」当成「数据缺失」**：订单表里某天 0 单，可能真的一单没有，也可能是导出截断。区分方法是对照上游系统的日汇总总量，或看该日是否有其他表的记录。
- **把「不完整周期」当完整周期**：最后一个月只有 8 天，它的月度值天然偏低。所有月度对比要么按日均，要么标注「部分周期」并排除出排名。

## 三、口径

### 必查清单

- 是否含取消 / 退款 / 测试单 / 内部账号 / 员工单
- 金额是否含税、含运费、已扣折扣
- 地域按发货地、收货地、注册地还是 IP
- 时间按事件发生、支付、发货还是入库
- 一个实体是否会被重复计数（多次状态变更、多条子记录）

### 判定

| 情况 | 处理 |
|---|---|
| 两个来源同指标差异 ≤ 1% | 可用，注明来源 |
| 差异 1%~5% | 必须解释差异来源，选一个为准 |
| 差异 > 5% | 视为口径不同，禁止混用；分开呈现并标注 |
| 同一实体多次计数 | 明确「去重前 / 去重后」，或改用最小可行动单元 |

**口径写不出来，就不要出结论。** 交付物里至少写一句「含什么、不含什么」。

## 四、分布（决定后续所有选择）

| 统计量 | 算法 | 判据 | 影响 |
|---|---|---|---|
| 集中度 | Top1% 记录贡献的占比 | > 50% 强长尾 | 一律 TopN 排序，不做全量平铺 |
| 偏态 | 均值 / 中位数 | > 1.5 右偏 | 用中位数、P90 描述，不用均值 |
| 离散度 | CV = σ / μ | > 1 波动大 | 必须补日粒度图，月汇总会掩盖脉冲 |
| 零值占比 | 0 值数 / 总数 | > 60% | 稀疏矩阵，考虑热力图或分面 |
| 头部占比 | Top5 类别占比 | > 80% | 图表只需 Top5 + 其他 |
| 负值 | 数值列 < 0 的条数 | > 0 | 单独成列（退款/冲销），不与正数直接求和 |

分位数口径统一用 `P25 / P50 / P75 / P90 / P99`，不要混用「百分位排名」。

## 五、七类前置陷阱

| 陷阱 | 识别信号 | 处理 |
|---|---|---|
| 缺月跳月 | 月份序列不连续 | 补 0、固定轴；跳月会让斜率失真 |
| 聚合抹掉维度 | 明细有该字段，汇总结果里没有 | 换粒度重取；接口不支持就按维度分次请求拼回 |
| 多口径混用 | 两套数字都「对」但总量不同 | 选一个权威口径，其余标注来源 |
| 快照值当常态 | 单日值是邻日数倍且前后回归 | 视为事件，单列标注；算趋势用 7 日中位数或剔除 |
| 事件时间 vs 入库时间 | 峰值日期与业务事实不符 | 全文统一一个时间口径，跨境先统一时区 |
| 单位不一致 | 元/千元、秒/分、件/箱混用 | 建表阶段统一，轴标题写单位 |
| 主键选错 | 去重后总量与来源对不上 | 回到「一、粒度」重测 |

## 六、分析阶段的阈值

### 6.1 存量 vs 增量

- 计算：`存量占比_i = 累计_i / 累计总`；`增量占比_i = (本期_i − 上期_i) / 总增量`
- 触发条件：占比差 ≥ **15pp**，或两个排序名次差 ≥ **2 位**
- 动作：并排展示两个排序，单独写一条结论

### 6.2 归因

- 每层下钻必须解释上层波动的 **≥ 50%**，否则换维度
- 贡献度取正负各 Top3，不要只看总量排名
- 停止条件：到「能直接采取动作」的粒度

### 6.3 基准

| 基准 | 适用 | 失效条件 |
|---|---|---|
| 环比 | 短期运营、季节性弱 | 周内效应 / 季节效应 > 20% |
| 同比 | 有季节性的业务 | 数据不足 12 个月（不得硬算） |
| 对峰值 | 产能、承载、库存 | 用历史最高当目标，长期显示「下滑」 |
| 对同类 | 横向比较 | 规模、阶段不可比 |

- 周期效应 > **20%** → 必须同比或季节调整
- 不完整周期 → 比日均，或不参与排名

### 6.4 四种变化

| 类型 | 判据 | 结论写法 |
|---|---|---|
| 真实趋势 | 连续 ≥ 3 期同向，幅度 > 2σ 或 > 10% | 「持续增长/下滑」 |
| 结构性替代 | A 降 B 升，合计平稳；份额交叉 | 「A 的量被 B 接管」 |
| 一次性脉冲 | 单日/单周尖峰，前后回归基线 | 「一次性事件，不构成趋势」 |
| 阶跃 / 断点 | 位移后不回归，形成新平台 | 「切换/政策导致的新常态」 |

### 6.5 异常

- 粗筛：`x > μ + 2σ`（约 5% 的点）；极端值 `> μ + 3σ`
- 稳健版（小样本或含极端值时）：`中位数 ± 3 × 1.4826 × MAD`
- 定性三类：业务事件 / 数据问题（重复、补录、时区）/ 口径问题（测试单、状态重复）
- **每个异常必须有结论**，不能只标色

### 6.6 指标失真

三问：

1. 分子、分母分别是谁？换分母结论会不会反？
2. 能否被单一维度「刷」高（把量堆到一个客户 / 一个国家）？
3. 是否应该单调？不单调说明有回冲或口径变更。

配比原则：广度配深度（覆盖数 + 活跃数）、存量配流量（累计 + 近 30 天）、绝对量配占比。

## 七、能力边界

交付物里必须写两句：

- 本数据能回答：……
- 本数据不能回答：……（原因）

判据三项：**维度是否齐全、时间是否够长、口径是否支持**。缺一项就明确说「不能」，不要用相关关系代替因果，也不要用代理指标硬撑。
