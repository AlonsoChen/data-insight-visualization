# 图表选型决策表

先定问题类型，再看数据形态，最后才选图。顺序反了，就会出现「手里有柱状图，于是所有问题都用柱状图」。

---

## 一、决策表

| 问题类型 | 数据形态 | 首选 | 备选 | 不要用 |
|---|---|---|---|---|
| 比较大小 / 排序 | 1 个维度，5~20 个类目 | 横向条形（降序） | 柱状 | 饼图、雷达图 |
| 时间趋势 | 时间 × 1~6 个系列 | 折线 | 面积（单系列） | 堆叠柱（看趋势差） |
| 构成 / 占比 | 时间 × 3~5 个部分 | 堆叠柱 | 100% 堆叠柱 | 多期饼图 |
| 份额迁移 | 时间 × 部分 | 100% 堆叠面积 | ≤3 期饼图 | 折线（会误读为绝对量） |
| 分布 | 单变量、大量样本 | 直方图 | 箱线 / 小提琴 | 均值柱 |
| 相关 | 两变量、样本 > 30 | 散点 | 气泡（第三维用大小） | 双轴折线（伪相关） |
| 二维矩阵 / 稀疏 | 行 × 列，多数为空 | 热力图 | 矩阵表 + 条件格式 | 分组柱（类别爆炸） |
| 进入 / 发生时序 | 实体 × 时间点 | 散点时间轴 | 甘特 / 条形 | 折线（连成假趋势） |
| 流向 / 转化 | 阶段 ≤ 4，节点 ≤ 20 | 漏斗 / 桑基 | 分阶段条形 | 饼图 |
| 达标 / 进度 | 单一目标值 | 子弹图 | 进度条 | 仪表盘（占位大、信息少） |
| 多维对比（≤ 4 维） | 少量实体 × 指标 | 小多图（分面） | 雷达（仅 ≤5 维） | 三维图 |

## 二、失效边界

选图标准不是「能画出来」，而是「还能不能读」。

| 图型 | 硬边界 | 失效时的处理 |
|---|---|---|
| 折线 | 类目 > 12 期；系列 > 6；大量 0 值 | 聚合到周/月；提供图例筛选；删掉贴底系列而不是留一条 0 线 |
| 堆叠柱 | 系列 > 5 | 中间层无法比较 → 小多图，或 Top4 + 其他 |
| 饼 / 环 | 类别 > 5；跨期比较 | 改横向条形；多期看份额改 100% 面积 |
| 横向条形 | 条目 > 20 | 截 Top15~20，其余归「其他」；必须降序（除非有自然顺序） |
| 散点 | 样本 < 30；严重重叠 | 相关性无意义；加透明度或抽样；不要从中读「趋势」 |
| 热力图 | 行 > 26；列 > 16 | 聚合或截取；颜色只能定性，必须给色阶图例 |
| 100% 堆叠面积 | 需要读绝对值 | 必配一张绝对量图，否则「份额涨了」可能只是总量跌得更快 |
| 双轴 | 量级差 < 10 倍；业务无关联 | 拆成两张图；保留时必须标单位、用同色、写明不构成因果 |
| 桑基 | 层级 > 3；节点 > 20 | 先聚合，否则变毛线团 |
| 箱线 | 组内样本 < 20 | 改「中位数 + P25/P75」误差条柱 |
| 雷达 | 维度 > 5；不可比量纲 | 改小多图或标准化后的条形 |

补充三条：

- **堆叠柱的中间层不可精确比较**。人眼只能可靠比较底层长度，所以「总共 8 个系列」的堆叠图几乎一定被误读。
- **热力图的空白是信息**。空格子通常代表「未发生 / 未进入」，不要用灰色填充掩盖。
- **面积与柱状的长度即数值**，y 轴必须从 0；折线可以不为 0，但要直接标注首尾值。

## 三、一图一问

每张图先写一句：

> 这张图回答：______？

写不出来 → 删。写出来但要两个问题 → 拆成两张。

允许的重叠只有两种：

1. **交叉校验**：两个视角算出来应该相等（如分项合计 vs 总量）
2. **不同粒度**：日粒度看脉冲、月粒度看趋势

除此之外的重复表达都是负资产，会稀释注意力。

---

## 四、信息架构

模块顺序复刻读者的提问顺序，不是数据库表的顺序：

```
规模多大 → 在怎么变 → 由什么构成 → 是谁在动 → 有没有异常 → 我想自己查某一组合
 KPI        趋势          构成          TopN/归因     异常/明细     自助查询
```

规则：

- 首屏 ≤ **6 个 KPI + 1 张主趋势图**；其余全部下移
- 每个模块只有一个主题，标题写结论
- 明细表放最后，不要放首屏
- 报告版按论证顺序串（不是并列），看板版按问题类型并列

## 五、交互克制

| 规则 | 说明 |
|---|---|
| 下钻 ≤ 3 层 | 全局 → 维度 A → 维度 B / 单点，第四层交给明细表 |
| 默认不级联 | 只有业务强绑定的才联动（选「欧洲」→ 国家列表只剩欧洲国家） |
| 全局与局部筛选要可区分 | 位置固定 + 文案写明作用范围 |
| 一键回全量 | 每个筛选都要能立刻回到全量 |
| 默认值选信息量最大的视图 | 通常是全量，或全量 + 排名第一的对照 |
| 状态不共享要说明 | 一句话写在图表下方，避免「选了 A 别处理应跟着变」的误解 |

判断级联是否合理：**级联后用户会不会误以为「别处没有数据」**。会，就不要级联。

## 六、标题与标注

| 写法 | 好 | 差 |
|---|---|---|
| 标题 | 「欧洲贡献了 77% 的增量」 | 「区域增量对比」 |
| 副标题 | 「2026Q3 vs 2025Q4，单位：台」 | 无 |
| 标注 | 「2025-11 单月进入 23 国」 | 让读者自己在图上数点 |

- 每图 ≤ **3 个标注**，多了变噪音
- 需要「用眼睛估一下再相减」的信息，一律写成文字标注
- 事件标注优先于装饰性标注
